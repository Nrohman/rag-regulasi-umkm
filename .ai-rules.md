# AI Generation Rules

## Tech Stack
- Framework: Next.js 14 (App Router), React 18, TypeScript.
- Styling: Tailwind CSS, Shadcn UI.
- AI/RAG: LangChain.js, OpenAI API / Gemini API, Pinecone (Vector DB).
- Database & ORM: PostgreSQL, Prisma ORM (Untuk riwayat sesi chat).
- State Management: Zustand (Untuk sidebar dan state global).

## Core System Directives
1. **Gemini-Like Multi-Session Chat:**
   - Implementasikan sistem multi-sesi. Sidebar menyimpan riwayat obrolan dari Prisma.
   - Gunakan `RunnableWithMessageHistory` dari LangChain agar AI mengingat konteks percakapan di setiap sesi.
   - Hasilkan (generate) judul sesi secara otomatis dari pesan pertama pengguna.
2. **Automated RAG Data Pipeline:**
   - Data hukum ditarik otomatis (Cron/API), lalu di-chunk dan disimpan di Pinecone.
   - Wajib menyuntikkan metadata: `document_id`, `status` (ACTIVE/REVOKED), `source_url`. AI HANYA menjawab dari vektor berstatus `ACTIVE`.
3. **Knowledge Audit & Transparency (Krusial):**
   - Setiap klaim hukum yang di-generate AI wajib memiliki *inline citation* yang bisa diklik.
   - Klik sitasi akan membuka `KnowledgeAuditModal.tsx` yang merender teks asli dari sumber dan tautan API/PDF.
